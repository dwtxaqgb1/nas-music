# NAS歌曲下载

基于落雪音乐的NAS音乐下载系统。

## 一键安装

```bash
bash <(curl -sSL "https://ghproxy.net/https://raw.githubusercontent.com/dwtxaqgb1/nas-music/main/install.sh?t=$(date +%s)")
```

## 功能

- 音乐搜索、播放、下载
- 音源仓库管理
- 播放模式切换
- 密码保护

## 系统要求

- Linux（X86/ARM均可）
- Docker + Docker Compose

## 访问

安装后访问 `http://NAS_IP:5200`，默认密码 `admin123`。
